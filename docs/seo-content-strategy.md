## 3. GEO (生成式引擎优化) 专项

### 原则
- AI爬虫(GPTBot, CCBot, anthropic-ai)不需要JS即可获取完整内容 → SSR
- 关键信息在HTML直接可见，不藏在图片/Tab/弹窗里
- 结构化数据用表格/列表，方便AI提取
- FAQ区块匹配自然语言疑问句
- llms.txt为AI爬虫提供全站地图

### llms.txt 内容结构
```
# 平台名称
> 平台一句话描述

## 核心页面
- /shanghai: 上海养老服务总览
- /shanghai/[district]: 各区列表 (16个区)
- /shanghai/[service-type]: 各服务类型 (5种)
- /provider/[slug]: 服务者详情

## 搜索
- /search?q={query}&district={district}: 组合搜索
- 支持按区域、服务类型、价格筛选

## 数据覆盖
- 上海16区 + 主要街道
- 5种养老服务类型
- N位服务者 (持续增长)
```

### 结构化数据检查清单
- [x] 首页: WebSite + Organization + SearchAction
- [x] 列表页: CollectionPage + ItemList + BreadcrumbList
- [x] 详情页: Person/LocalBusiness + Service + AggregateRating + Review
- [x] FAQ: 每页3-5个FAQ
- [ ] Google Rich Results测试通过
- [ ] Schema validator 0错误
- [ ] 所有页面有canonical URL

### AI搜索引文策略

目标：当用户在豆包/Kimi/元宝/ChatGPT中搜索养老问题时，
     我们的内容被引用为来源。

怎么做：
1. **内容质量**：每个页面提供独特的、具体的数据点（价格、资质、评价），
   而不是泛泛的描述
2. **结构化FAQ**：用自然疑问句做H2，答案直接在HTML中，
   让AI能精确匹配用户问题
3. **权威信号**：
   - 服务者资质证书信息（JSON-LD Credential）
   - 真实姓名+电话（LocalBusiness信号）
   - 用户评价（Review schema）
   - 明确的地址信息（PostalAddress）
4. **内容新鲜度**：lastmod在sitemap中正确反映更新频率
5. **引用友好**：关键数据用 `<table>` 或 `<dl>` 结构化，
   价格用 `<meta itemprop="priceRange">` 标注
